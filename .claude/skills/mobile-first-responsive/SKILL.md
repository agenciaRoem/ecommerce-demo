# Mobile-first responsive design

## Cuándo usar
- Al construir pantallas de stockeo o de venta.
- Al revisar vistas que se ven mal en móvil.

## Reglas
- Diseña primero para ancho de 360px y amplía con breakpoints.
- Botones con área táctil mínima de 44px.
- Prioriza las acciones principales del flujo de stockeo en la parte visible sin desplazarse.
- Evita tablas anchas en móvil; usa listas o tarjetas.

## Validación
- Prueba el flujo completo en un viewport de 360px sin desplazamiento horizontal.
